# Apito Final

Site de futebol feito em HTML, CSS e JavaScript puros para a disciplina Desenvolvimento de Interfaces.

## Como abrir
Abra `index.html` no navegador.

## Arquivos
- `index.html`: estrutura das telas
- `style.css`: cores (variáveis), layout e temas claro/escuro
- `script.js`: rotas, pesquisa, carrossel, formulários e acessibilidade
